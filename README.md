# Doxo Promo LLC - Enterprise Accounting & Financial Advisory

A modern, high-performance financial advisory web platform built with Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Framer Motion, and Lucide React.

## 🚀 Key Features

- **Strategic Accounting & Tax Advisory**: Enterprise bookkeeping, corporate tax optimization, and AICPA-supervised standard workflows.
- **Fractional CFO & Capital Structuring**: 13-week predictive cash flow models, SBA debt packaging, and board presentation decks.
- **Interactive ROI Estimator**: Client-side financial calculator for estimating capital & tax efficiency gains.
- **Interactive Consultation Portals**: Modal booking and full contact directory with real-time validation and confetti celebration feedback.
- **Comprehensive Route Structure**:
  - `/` - Strategic corporate overview, service highlights, ROI estimator, pricing preview, and client results.
  - `/services` - Filterable 6-pillar service suite, 4-step engagement roadmap, and service FAQs.
  - `/pricing` - Transparent 6-package pricing tier matrix with monthly/annual discount toggle and feature comparison.
  - `/about` - Corporate mission, 4 foundational principles, leadership team, and track record timeline.
  - `/contact` - Corporate directory, direct partner lines, and NDA-protected consultation form.

## 🛠 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations & Icons**: [Framer Motion](https://www.framer.com/motion/), [Lucide React](https://lucide.dev/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Feedback Effects**: [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti)

## 📦 Getting Started

### Prerequisites
- Node.js 18+ or Node.js 20+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/saimsultan380/smartpromo.git

# Navigate to project directory
cd smartpromo

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build for Production

```bash
npm run build
npm run start
```
